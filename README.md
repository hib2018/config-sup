# config-sup（試作版）

公開GitHubリポジトリをPi SDKエージェントが読み取り専用で解析し、ローカル設定の適用先を項目ごとに探します。ユーザーは値を編集して差分を確認し、明示的に適用します。取得したコードの実行やGitHubへの書き込みは行いません。

## 起動

Go 1.23以降、Node.js 22以降、Gitと、Piで設定済みのモデル・認証（Piの `/login`・`/model`）が必要です。

```sh
npm install
npm start
```

ChromeまたはEdgeで `http://127.0.0.1:4173` を開き、GitHub URLを入力します。画面でリポジトリ解析とローカル設定検索の両方に同意してください。ローカル検索範囲は `~/.config` と `~/Library/Application Support` の通常ファイル（JSONのみ）です。エージェントに渡すローカル情報はファイル名・キー名・型で、**ローカル設定値は送信しません**。リポジトリから読んだ内容とローカルのキー情報は、Piで選択したモデルの提供先に送信される場合があります。

エージェントが特定した適用先を確認し、値を編集します。明示された選択肢はプルダウン、それ以外は「自由入力（文字列）」「数値を入力」と表示されます。差分を確認してから「この変更を適用」を押してください。適用先が外部から変更されていたら適用を停止します。

## 制限

- エージェントには追跡済みリポジトリファイルの検索・読み取り、対象ディレクトリ内のローカルJSONファイルの名前・キー・型の検索ツールのみ与えます。取得元やローカルのコード、スキル、拡張は実行しません。リポジトリ読み取りは1ファイル100KB・合計300KB・最大20回、解析は最大120秒です。ローカルは最大500ファイル・各100キー。AIによる抽出・説明・対応付け・選択肢は参考情報であり、網羅性・正確性は保証しません。
- **適用先は現在、通常のJSONファイルにある同名・同型の既存キーのみ**。JSONC/YAML/TOMLのローカルファイルや配列・null・新しいキーの書き戻しは未対応です。適用先を特定できない項目は表示のみで編集不可です。
- JSONファイル全体を整形して書き直します。事前のバックアップを推奨します。複数ファイルへの適用は一括トランザクションではないため、途中の書き込み失敗時は一部だけ反映され得ます。稼働中のツールへの反映は行いません。
- 解析結果と適用計画はサーバーのメモリに20分間だけ保持します。取得したGitHubリポジトリは一時ディレクトリから解析終了後に削除します。GitHub取得は最大30秒で中止します。Web UIのTauri対応は将来の課題です。

`npm test` で基本的な検証を実行できます。
