# config-sup（試作版）

公開GitHubリポジトリをPi SDKのエージェントに読み取り専用で解析させ、見つかった設定項目をWeb UIに表示します。ユーザーが選んだローカルJSONファイルの同名・同型のキーだけ編集・適用できます。取得したコードは実行せず、GitHubへの書き込みも行いません。

## 起動

Go 1.23以降、Node.js 22以降、Gitと、Piで設定済みのモデル・認証（Piの `/login`・`/model`）が必要です。

```sh
npm install
npm start
```

ChromeまたはEdgeで `http://127.0.0.1:4173` を開き、GitHub URLを入力します。解析前に「Piのモデルに設定ファイルを送信して解析する」にチェックを入れてください。エージェントが読み取ったリポジトリのファイル内容は、設定したモデルの提供先に送信される場合があります。解析後、設定ファイルを選び、**適用先のローカルJSONファイルを選択**して、編集→差分確認→適用の順に操作します。選択済みの適用先が外部から変更された場合は適用を中止します。

## 制限

- エージェントには追跡済みファイル名の検索とファイル本体の読み取りツールだけを与えます。取得元のコード、スキル、拡張は実行しません。読み取りは1ファイル100KB・合計300KB・最大20回、解析は最大120秒です。出力は最大30ファイル・各100項目に制限します。AIによる抽出・説明は参考情報であり、網羅性・正確性は保証しません。
- JSONCやソースコードから設定項目を発見することはできますが、**適用先は現在JSONのみ**。同名・同型の既存キーだけ編集できます。配列・nullや形式固有の設定ファイルの書き戻しは未対応です。
- 適用先のJSONファイル全体を整形して書き直すため、事前のバックアップを推奨します。稼働中のツールへの反映は行いません。
- GitHubからは全ファイルをcheckoutせず、読み取るファイルだけ取得します。取得は最大30秒で中止します。大きなリポジトリの取得量を厳密に制限するものではありません。Web UIのTauri対応は将来の課題です。

`npm test` で基本的な検証を実行できます。
