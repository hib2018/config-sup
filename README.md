# config-sup（CLI試作・第一段階）

自然言語で指定したツールのローカル設定を探し、項目の現在値を一覧表示し、1項目の変更を人間の承認後に適用します。Web UI構想は終了し、既存のWebサーバーとブラウザ用コードは移行途中のため残っていますが、`npm start` では起動しません。

## 起動

Go 1.23以降、Node.js 22以降、GitとPiで設定済みのモデル・認証（Piの `/login`・`/model`）が必要です。**対話端末から**実行してください。

```sh
npm install
npm start -- "Zed エディタ"
# または npm start で対象ツールを質問に答える
```

1. `~/.config` と `~/Library/Application Support` のローカル設定ファイルを探し、**ファイル名・キー名・型（設定値は除く）をPiモデルに送る**ことへの同意を求めます。承認されなければ探索しません。
2. エージェントが対象ファイル候補を特定します。曖昧な場合は候補から選びます。一覧には「設定項目名 = 現在の内容」だけを表示します。
3. 番号で1項目と新しい値を入力します。元ファイルはまだ変更せず、パーサーで変更案を検証します。
4. 設定内容を `変更前 → 変更後` で示し、明示的な `yes` の後にだけ実ファイルを変更します。承認前や外部でファイルが変わった場合は適用しません。

## 現段階の制限

- 探索範囲は `~/.config` と `~/Library/Application Support` に固定。**見つからなかった場合に承認を得て他のディレクトリを探索する処理は未実装**で、勝手に拡張しません。
- 現段階のエージェントはローカルのファイル名・キー名・型から対象を特定します。コード解析、tree-sitterによる選択肢の抽出、TUI、複数項目の一括編集は未実装です。真偽値は `true`/`false`、その他の値は自由入力です。
- 対応するローカル設定はJSON・YAML（.yaml/.yml）・TOML（.toml）の既存の文字列・数値・真偽値キー。JSONは全体を整形して書き直し、YAML/TOMLは対象の単純な値だけを置換します。JSONCの書き戻し、配列・null・新しいキーは未対応です。
- 変更前にバックアップを取る機能はまだありません。重要な設定は事前にバックアップしてください。CLIは対話端末を要求し、`yes` 以外では適用しません。設定ツールの再起動はしません。

`npm test` で基本的な検証を実行できます。
