# config-sup（試作版）

公開GitHubリポジトリのJSON設定ファイルを解析し、ローカルJSONファイルの同じキー・型の項目をWeb UIから変更します。取得したコードは起動せず、GitHubへ書き込みません。

## 起動

Go 1.23以降、Node.js 22以降（ブラウザ用 TypeScript のビルド）、Git が必要です。バックエンドの解析・配信処理は Go で実装し、ソースコードは `src/` にまとめています。

```sh
npm install
npm start
```

`http://127.0.0.1:4173` をChromeまたはEdgeで開きます（ローカルファイルへの書き込みにFile System Access APIを使用）。GitHub URLを入力し、解析元のJSON設定を選び、適用先の**ローカルJSONファイルを選択**します。編集→差分確認→適用の順に操作します。候補にないファイルもダイアログから選択できますが、同名・同型のキーだけ編集できます。選択済みファイルが外部から変更された場合、適用は中止されます。

エージェントによる説明を使う場合のみ `OPENAI_API_KEY` を環境変数に設定し、UIのチェックを入れてください。解析した設定項目と値がOpenAI APIへ送信されます（任意で `OPENAI_MODEL` を指定）。エージェントは説明のみを生成し、選択肢や制約、ファイルの変更には関与しません。未設定やAPI障害でも静的解析は利用できます。

## 制限

- 公開GitHubリポジトリにある、名前が `config.json`・`settings.json`・`*-config.json` 等に一致するJSON設定のみ。深さ5階層・最大30ファイル・各100KB・100項目まで。配列・null・JSONC・YAML・スキーマからの選択肢抽出には未対応。
- 意味の説明はAI由来の参考情報です。適用先ファイルのJSON全体を整形して書き直すため、適用前にバックアップを推奨します。稼働中のツールへの反映は行いません。
- 解析はローカルサーバー、編集・適用はブラウザで行います。Tauri対応は将来の課題です。GitHubからの取得は最大30秒で中止しますが、大きなリポジトリの取得量を厳密に制限するものではありません。根拠はファイルとキーの表示までで、行番号の表示は未対応です。

`npm test`（または `go test ./src`）で基本的な検証を実行できます。`npm run build && go run ./src` でも起動できます。
